# Dashboard Inventario Industrial

Dashboard web para gestión de inventario industrial. Consume la API REST [InventarioIndustrialAPI](https://github.com/luisfelipems20/InventarioIndustrialAPI) y muestra el estado del stock en tiempo real.

## Tecnologías
- HTML5
- CSS3
- JavaScript Vanilla
- Bootstrap 5
- Bootstrap Icons

## Funcionalidades
- Resumen de stock total, crítico y normal
- Tabla de repuestos con estado visual
- Agregar nuevos repuestos
- Eliminar repuestos
- Indicador de última actualización

## Requisitos
- Tener corriendo [InventarioIndustrialAPI](https://github.com/luisfelipems20/InventarioIndustrialAPI) en localhost:5131
